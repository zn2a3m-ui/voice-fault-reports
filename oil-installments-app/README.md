# دفتر الزيت — إدارة البيع بالأقساط

تطبيق Android مستقل لإدارة مبيعات تنكات الزيت والأقساط والتحصيل. كل ملفات التطبيق داخل هذا المجلد؛ لا يغيّر ملفات التطبيقين الآخرين.

## قواعد البيع المنقولة من الملف الأصلي
- سعر التنكة 130 ديناراً.
- 9 أقساط شهرية: 8 × 15 ديناراً، والأخير 10 دنانير لكل تنكة.
- السعر الإجمالي وعدد التنكات يحسبان تلقائياً.

## الوظائف
لوحة مؤشرات، سجل زبائن وبحث، تفاصيل كل زبون، تسديد/إلغاء القسط، جدول شهري، تذكير واتساب يدوي، تفضيل تذكير تلقائي لكل زبون على حدة مع تسجيل موافقته، تصدير جهات اتصال CSV، ونسخ احتياطي JSON واستعادة.

## واتساب التلقائي — حالة التنفيذ
يمكن من كشف حساب كل زبون حفظ موافقته على رسائل التذكير وتشغيل/إيقاف خيار التذكير التلقائي له بشكل مستقل. هذه المرحلة تحفظ التفضيل محلياً فقط ولا ترسل رسائل تلقائياً بعد. لتفعيل الإرسال الفعلي حتى عند إغلاق التطبيق، يلزم إعداد WhatsApp Business Cloud API وربطه بخدمة خلفية آمنة وجدولة للأقساط. يجب حفظ مفاتيح API في الخادم فقط، والحصول على موافقة الزبون واستخدام قوالب رسائل معتمدة عندما تتطلبها سياسات واتساب. لا توجد حالياً بيانات اعتماد أو ربط حي، لذلك لن تُرسل رسائل من هذا الإصدار.

## البيانات
تُحفظ بيانات النسخة الحالية محلياً على الجهاز في localStorage بالمفتاح installments-v1. أُضيفت واجهة اختيارية لتسجيل الدخول بالبريد وكلمة المرور وربط مشروع Supabase ومزامنة البيانات، لكنها لا تعمل قبل إنشاء مشروع مستقل وتطبيق ملفات SQL وإدخال رابط المشروع ومفتاحه العام داخل التطبيق. بيانات الجهاز تبقى محفوظة محلياً في كل الأحوال. خذ نسخة احتياطية قبل تغيير الهاتف أو حذف التطبيق.

## تسجيل الدخول والمزامنة السحابية — مرحلة التجهيز

أُضيفت واجهة حساب داخل التطبيق (إنشاء حساب، تسجيل الدخول، تسجيل الخروج، ومزامنة يدوية) باستخدام Supabase Auth وData REST API دون إضافة مفاتيح خادم إلى التطبيق. إعداد الرابط والمفتاح العام يُحفظ محلياً على الجهاز. يمكن استخدام مفتاح Publishable أو anon العام فقط؛ يمنع وضع service_role أو مفاتيح Meta في التطبيق.

الملفات:
- `www/supabase-sync.js`: تسجيل الدخول وتجديد الجلسة والمزامنة.
- `supabase/sql/local-first-sync.sql`: حقول ربط السجلات المحلية بالسحابية وبيانات البيع والطوابع الزمنية، مع صلاحيات Data API للمستخدم المسجل.
- تبقى `installments-v1` هي قاعدة البيانات المحلية؛ لا تُحذف عند تسجيل الخروج أو فشل الشبكة.
- تُزامن سجلات الزبائن والأقساط، ويُستخدم وقت تعديل الزبون للمقارنة بين النسخ. حذف الزبون يسجل علامة حذف محلية تُرسل عند المزامنة التالية.
- يلزم تطبيق `whatsapp-reminders-schema.sql` أولاً ثم `local-first-sync.sql` على مشروع دفتر الزيت. لا تطبقها على المشروع الرياضي.
- يجب تفعيل تأكيد البريد أو ضبط إعدادات Auth المناسبة في لوحة المشروع. بعد التسجيل مع تفعيل تأكيد البريد، افحص البريد ثم سجّل الدخول.
- لا تتزامن بيانات هذا التطبيق فعلياً قبل إعداد مشروع مخصص وإكمال SQL. ولا يعمل الإرسال التلقائي لواتساب حتى نشر الوظيفة وربط Meta كما هو موضح أدناه.

المزامنة الحالية ترفع التغييرات المحلية الأحدث وتستورد السجلات السحابية الأحدث أو غير الموجودة محلياً. لا توجد بعد آلية مزامنة فورية أو عمل بالخلفية؛ استخدم زر «مزامنة الآن» بعد تسجيل الدخول.

## تجهيز الإرسال التلقائي — ملفات الخلفية
أُضيفت ملفات تأسيسية فقط، ولم تُنشر إلى أي مشروع Supabase بعد:
- `supabase/sql/whatsapp-reminders-schema.sql`: جداول العملاء والأقساط وسجل الإرسال، مع RLS وربط كل سجل بمالك حسابه.
- `supabase/functions/send-oil-installment-reminders/index.ts`: عامل مجدول يتحقق من موافقة العميل والتفعيل ورقم الهاتف، ويرسل قالب WhatsApp معتمداً، ويسجل محاولات الإرسال لمنع التكرار في اليوم نفسه. يعمل على توقيت عمّان.
- `supabase/sql/schedule-reminders.sql`: مثال جدولة يومية الساعة 09:00 صباحاً بتوقيت عمّان.

**قبل التشغيل الحقيقي:** التطبيق لا يزامن بياناته المحلية إلى الجداول السحابية بعد، لذلك لا يمكن للعامل رؤية زبائن التطبيق حتى نضيف تسجيل الدخول والمزامنة الآمنة. كما يجب إنشاء مشروع Supabase مستقل لدفتر الزيت (لا نستخدم مشروع `arabic-sports-platform` لأنه مشروع آخر)، تطبيق مخطط SQL، نشر Edge Function، وإضافة أسرار الخادم التالية: `OIL_REMINDER_CRON_SECRET`, `WHATSAPP_ACCESS_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_API_VERSION`, `WHATSAPP_TEMPLATE_NAME`, `WHATSAPP_TEMPLATE_LANGUAGE`. تُحفظ قيمة رابط المشروع وسر الجدولة ومفتاح Supabase السري (وليس المفتاح العام) في Supabase Vault. لا تضع هذه الأسرار في التطبيق أو GitHub.

قالب واتساب المعتمد يجب أن يحتوي ثلاثة متغيرات في نص الرسالة بالترتيب: اسم الزبون، مبلغ القسط، تاريخ الاستحقاق. يلزم تسجيل موافقة الزبون فعلياً قبل تشغيل التذكير. لا تُرسل رسائل من ملفات الخلفية قبل ربط حساب Meta ورقم الأعمال والقالب المعتمد وإكمال المزامنة.

لا نستعيد أو نفعّل مشروع Supabase الرياضي المتوقف ولا ننشئ مشروعاً جديداً دون تحديد مساحة العمل/المنظمة ومراجعة أي تكلفة.

## بناء APK
```bash
npm install
npm run check
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```
ينتج APK في android/app/build/outputs/apk/debug/app-debug.apk. حزمة Debug للاختبار وليست موقعة للنشر على Google Play.
