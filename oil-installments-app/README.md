# دفتر الزيت — إدارة البيع بالأقساط

تطبيق Android مستقل لإدارة مبيعات تنكات الزيت والأقساط والتحصيل. كل ملفات التطبيق داخل هذا المجلد؛ لا يغيّر ملفات التطبيقين الآخرين.

## قواعد البيع المنقولة من الملف الأصلي
- سعر التنكة 130 ديناراً.
- 9 أقساط شهرية: 8 × 15 ديناراً، والأخير 10 دنانير لكل تنكة.
- السعر الإجمالي وعدد التنكات يحسبان تلقائياً.

## الوظائف
لوحة مؤشرات، سجل زبائن وبحث، تفاصيل كل زبون، تسديد/إلغاء القسط، جدول شهري، تذكير واتساب يدوي، تفضيل تذكير تلقائي لكل زبون على حدة مع تسجيل موافقته، تصدير جهات اتصال CSV، ونسخ احتياطي JSON واستعادة.

## واتساب التلقائي — حالة التنفيذ
يمكن من كشف حساب كل زبون حفظ موافقته على رسائل التذكير وتشغيل/إيقاف خيار التذكير التلقائي له بشكل مستقل. هذه المرحلة تحفظ التفضيل محلياً فقط ولا ترسل رسائل تلقائياً بعد. لتفعيل الإرسال الفعلي حتى عند إغلاق التطبيق، يلزم إعداد WhatsApp Business Cloud API وربطه بخدمة خلفية آمنة وجدولة للأقساط. يجب حفظ مفاتيح API في الخادم فقط، والحصول على موافقة الزبون واستخدام قوالب رسائل معتمدة عندما تتطلبها سياسات واتساب. لا توجد حالياً بيانات اعتماد أو ربط حي، لذلك لن تُرسل رسائل من هذا الإصدار.

## البيانات
تُحفظ محلياً على الجهاز في localStorage بالمفتاح installments-v1. لا توجد مزامنة سحابية في الإصدار الأول. خذ نسخة احتياطية قبل تغيير الهاتف أو حذف التطبيق.

## بناء APK
```bash
npm install
npm run check
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
```
ينتج APK في android/app/build/outputs/apk/debug/app-debug.apk. حزمة Debug للاختبار وليست موقعة للنشر على Google Play.
