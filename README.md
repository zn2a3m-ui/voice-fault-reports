# مساعد مشرف الصيانة

تطبيق ويب عربي (PWA) مخصص لمتابعة الصيانة والإنتاج في مسالخ الدواجن ومصانع تجهيز الدواجن. يعمل على الهاتف ويمكن تثبيته من Chrome، وتصل التحديثات دون حذف التطبيق أو بياناته المحلية.

## الأقسام والوظائف

- **الأعطال والملاحظات الفنية:** تسجيل نصي أو صوتي، تصنيف حسب التخصص والحالة، حفظ النص الأصلي دون تعديل، وإعداد صياغة إدارية وفنية.
- **التحليل الفني الأولي:** تنظيم الحالة إلى معلومات مؤكدة واحتمالات وفحوصات آمنة ومراجع عامة ذات صلة. لا يُعد تشخيصاً نهائياً ولا بديلاً عن دليل موديل الماكينة.
- **تقارير الإنتاج:** وصف الحالة بصوت أو نص، ثم صياغة تقرير مهني يحدد من السياق ما إذا كانت الحالة تقرير إنتاج أو مشكلة إنتاج والجهة الأنسب.
- **تقارير الشفت:** توثيق الأعمال المنجزة والمتبقية والملاحظات.
- **التسليم والاستلام:** حفظ الملاحظات المفتوحة ومتابعتها بين الشفتات.
- **قطع الغيار والمواد:** تسجيل اسم القطعة والكمية والتخصص والأولوية وسبب الطلب.
- **السجلات:** عرض السجلات، نسخ ومشاركة وتنزيل النصوص.
- **النسخ الاحتياطي:** تنزيل نسخة JSON واستيرادها بعد التأكيد.
- **المزامنة:** حفظ محلي ومزامنة سحابية لحساب المستخدم عبر Supabase، مع سياسات RLS على جداول البيانات.

## الصوت والذكاء الاصطناعي

- يستخدم الإملاء الصوتي واجهة التعرف الصوتي المتاحة في المتصفح؛ دعم اللغة واللهجة وجودة النص تعتمد على Chrome وخدمة التعرف في الجهاز والاتصال.
- تظهر مسودة الكلام أثناء التسجيل، ويُثبّت النص عند إيقاف التسجيل. يجب مراجعة أسماء المعدات والأرقام قبل اعتماد التقرير.
- الصياغة والتحليل الفني يعملان من خلال Supabase Edge Function مع Groq. مفتاح المزود محفوظ في أسرار الخادم ولا يوضع في ملفات الواجهة.
- توفر Groq وحدود الاستخدام تخضع لسياسة المزود الحالية؛ لا يضمن التطبيق توفر المعالجة بلا حدود.
- لا يفترض التطبيق سبب العطل أو الإجراء المنفذ أو نجاح الإصلاح أو أرقام الإنتاج غير المذكورة.

## الأمان والبيانات

- كل جدول سحابي مفعّل عليه RLS، والسياسات تقصر القراءة والكتابة على صاحب السجل المصادق عليه.
- يستخدم التطبيق Publishable key في المتصفح، ولا يضع مفاتيح الخدمة السرية في الواجهة.
- تبقى البيانات المحلية على الجهاز عند تسجيل الخروج. نزّل نسخة احتياطية دورياً، ولا تحذف بيانات المتصفح قبل التأكد من وجود نسخة آمنة.
- لا تشارك كلمة المرور أو رموز الجلسة مع أي شخص.

## النشر والتحديث

يتم النشر تلقائياً عبر GitHub Actions عند تحديث الفرع `main`. بعد اكتمال النشر، افتح رابط GitHub Pages من Chrome على Android وثبّت التطبيق عبر «إضافة إلى الشاشة الرئيسية». تُحدّث ذاكرة التطبيق المؤقتة مع كل إصدار جديد.
