# مساعد مشرف الصيانة

تطبيق ويب عربي مهيأ للهاتف لمساندة مشرف الصيانة في متابعة الميكانيك والكهرباء والمواسير خلال الشفت.

## الوظائف الحالية
- تسجيل الأعطال والملاحظات كتابةً أو بالصوت (حسب دعم المتصفح).
- تصنيف كل ملاحظة حسب التخصص وحالة العمل.
- حفظ النص الأصلي كما أدخله المستخدم، دون تعديل تلقائي.
- إعداد تقرير أعمال الشفت: المنجز، قيد المتابعة، والملاحظات.
- سجل تسليم واستلام الأعمال بين الشفتات.
- تسجيل طلبات قطع الغيار والمواد مع الكمية والأولوية والسبب.
- نسخ النصوص ومشاركتها وتنزيلها.
- نسخ احتياطي واستعادة بصيغة JSON.
- واجهة عربية RTL وتثبيت كتطبيق PWA.
- ترحيل أولي لسجلات الأعطال القديمة من مفتاح التخزين السابق عند أول تشغيل للنسخة الجديدة.

## حالة الذكاء الاصطناعي
واجهة الصياغة الذكية موجودة، لكنها **غير مفعّلة بعد**. لا يتم إرسال بيانات إلى أي مزود ذكاء اصطناعي حالياً. يلزم نشر خدمة خلفية آمنة تحفظ مفتاح المزود كسرّ على الخادم، مع مصادقة وصلاحيات مناسبة. لا تضع مفتاح API داخل ملفات الواجهة أو إعدادات المتصفح.

قبل ربط الخدمة، يجب تحديد مشروع Supabase مخصص أو الموافقة صراحة على استخدام مشروع موجود؛ المشروع المتاح حالياً يحمل اسم `arabic-sports-platform` ويبدو مخصصاً لتطبيق آخر، لذلك لا يتم استخدامه تلقائياً.

## البيانات والخصوصية
- تُحفظ السجلات محلياً داخل المتصفح على الجهاز الحالي.
- لا توجد مزامنة بين الأجهزة أو حسابات مستخدمين في هذه النسخة.
- امسح بيانات المتصفح أو غيّر الجهاز فقط بعد تنزيل نسخة احتياطية.
- لا تسجل بيانات شخصية حساسة أو معلومات تشغيلية سرية إلا وفق سياسة المنشأة.
- راجع كل تقرير قبل مشاركته واعتماده.

## النشر على GitHub Pages
1. من إعدادات المستودع افتح **Settings → Pages**.
2. اختر **GitHub Actions** كمصدر للنشر.
3. شغّل سير العمل من تبويب **Actions** أو ادفع تحديثاً إلى `main`.
4. بعد نجاح النشر افتح رابط Pages وثبّت التطبيق من Chrome على Android عبر **إضافة إلى الشاشة الرئيسية**.

## ملاحظات
- يفضل استخدام Chrome والسماح بالميكروفون للتسجيل الصوتي.
- التعرف على الكلام يعتمد على خدمة المتصفح وقد يخطئ في أسماء المعدات والأرقام؛ راجع النص قبل حفظه.
- التطبيق لا يقرر أن العطل أُصلح ولا يستنتج سبباً فنياً غير مذكور.
