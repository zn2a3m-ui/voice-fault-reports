# مساعد التقارير والأعطال

تطبيق ويب عربي لتسجيل الأعطال صوتياً أو كتابتها، ثم جمعها في تقرير واحد ومشاركته.

## المزايا الحالية
- واجهة عربية RTL مناسبة للهاتف.
- إدخال الأعطال كتابةً أو بالصوت عند دعم المتصفح للتعرف على الكلام.
- إضافة عدة أعطال مع ترقيم تلقائي.
- تعديل أي عطل أو حذفه.
- حفظ تلقائي محلياً في المتصفح.
- نسخ التقرير كاملاً ومشاركته وتنزيله كملف TXT.
- إضافة التاريخ والوقت وعدد الأعطال إلى التقرير.
- ملف تثبيت PWA وأيقونة للتطبيق.
- تخزين ملفات التطبيق مؤقتاً للعمل دون اتصال بعد أول تحميل ناجح.

## نشر التطبيق على GitHub Pages
1. افتح **Settings** في المستودع.
2. اختر **Pages** من القائمة.
3. ضمن **Build and deployment** اختر **GitHub Actions** كمصدر.
4. بعد حفظ الإعداد، ادفع أي تحديث إلى فرع `main` أو شغّل سير العمل يدوياً من تبويب **Actions**.
5. عند نجاح النشر سيظهر رابط الموقع في صفحة Pages وفي تفاصيل عملية النشر.

ملف سير العمل موجود في `.github/workflows/deploy-pages.yml`. يجب تمكين Pages يدوياً من إعدادات المستودع أول مرة. قد تتطلب استضافة مستودع خاص خطة GitHub تسمح بصفحات المستودعات الخاصة.

## تثبيت التطبيق على الهاتف
بعد فتح رابط الموقع المنشور عبر HTTPS في Chrome على Android، افتح قائمة المتصفح واختر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** إذا ظهر الخيار.

## ملاحظات وحدود مهمة
- التعرف الصوتي يعتمد على دعم المتصفح وإذن الميكروفون؛ استخدم Chrome واسمح بالميكروفون.
- النص الصوتي يُسجّل كما يتعرف عليه المتصفح. لا يوجد حتى الآن تصحيح لغوي بالذكاء الاصطناعي.
- عند إضافة التصحيح الذكي لاحقاً، يجب أن يقتصر على الإملاء واللغة دون إعادة صياغة أو تغيير أسماء المعدات والمصطلحات أو إضافة/حذف معلومات.
- البيانات محفوظة على الجهاز والمتصفح فقط، ولا توجد مزامنة سحابية أو حسابات مستخدمين حالياً.
- مشاركة التقرير تفتح خيارات المشاركة ولا ترسله تلقائياً.
