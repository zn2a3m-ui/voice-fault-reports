# مساعد التقارير والأعطال

صفحة ويب عربية لتسجيل الأعطال صوتياً أو كتابتها، ثم جمعها في تقرير واحد.

## المزايا
- واجهة عربية مناسبة للهاتف.
- إدخال صوتي عبر التعرف على الكلام في المتصفح عند دعمه والسماح بالميكروفون.
- إضافة عدة أعطال مع ترقيم تلقائي.
- تعديل الأعطال وحذفها.
- حفظ محلي داخل المتصفح باستخدام `localStorage`.
- نسخ التقرير كاملاً أو فتح مشاركة واتساب.

## التشغيل
افتح `index.html` عبر استضافة HTTPS، ثم استخدم Chrome على Android واسمح للصفحة بالوصول إلى الميكروفون. قد لا يعمل التعرف الصوتي عند فتح الملف مباشرة أو في المتصفحات غير الداعمة.

## ملاحظات مهمة
- النص الصوتي يظهر كما يتعرف عليه المتصفح؛ **لا يوجد حالياً تصحيح لغوي بالذكاء الاصطناعي**.
- راجع أسماء المعدات والمصطلحات الفنية قبل اعتماد التقرير.
- البيانات محفوظة محلياً على الجهاز والمتصفح، وليست متزامنة مع خادم.
- مشاركة واتساب تفتح رسالة جاهزة ولا ترسلها تلقائياً.
