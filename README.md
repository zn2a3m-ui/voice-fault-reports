# مساعد مشرف الصيانة

تطبيق ويب عربي مهيأ للهاتف لمساندة مشرف الصيانة في إدارة أعمال الشفت ومتابعة الميكانيك والكهرباء والمواسير والتمديدات.

## الوظائف
- تسجيل الأعطال والملاحظات كتابةً أو بالصوت (بحسب دعم المتصفح).
- تصنيف الأعطال حسب التخصص والحالة.
- الاحتفاظ بالنص الأصلي دون تعديل تلقائي.
- نسخ الأعطال فقط دون إضافة تاريخ أو وقت إلى النص المنسوخ.
- إعداد تقارير الشفت: الأعمال المنجزة، الأعمال قيد المتابعة، والملاحظات.
- سجل تسليم واستلام الأعمال بين الشفتات.
- طلبات قطع الغيار والمواد مع الكمية والأولوية والسبب.
- نسخ ومشاركة وتنزيل السجلات.
- نسخ احتياطي واستعادة بصيغة JSON.
- واجهة عربية RTL وتثبيت كتطبيق PWA.

## الدخول والمزامنة السحابية
- يرتبط التطبيق بمشروع Supabase مستقل مخصص للصيانة.
- تسجيل الدخول بالبريد الإلكتروني وكلمة المرور عبر Supabase Auth.
- مزامنة سجلات الأعطال وتقارير الشفت والتسليم وطلبات القطع مع قاعدة البيانات.
- يحتفظ التطبيق بنسخة محلية، ويضيف السجلات المحلية إلى الحساب عند أول مزامنة دون حذف السجلات السحابية الموجودة.
- سياسات RLS مفعّلة على الجداول، والوصول للبيانات محصور بالمستخدم المصادق عليه ومالك السجل.
- مفاتيح الخدمة السرية لا توضع في ملفات الواجهة. المفتاح المنشور المستخدم في المتصفح هو Publishable key فقط.

### إعداد حساب المالك
1. افتح التطبيق وأنشئ حساب المالك باستخدام بريدك الإلكتروني وكلمة مرور قوية.
2. إذا طُلب تأكيد البريد، افتح رسالة Supabase وأكّد البريد ثم سجّل الدخول.
3. بعد إنشاء حسابك الأول، عطّل التسجيل العام من إعدادات Supabase Authentication حتى يبقى الاستخدام خاصاً بك في المرحلة الحالية.
4. سجّل الدخول من التطبيق واضغط «مزامنة الآن» عند الحاجة. لا تشارك كلمة المرور مع أي شخص.

## حالة المساعد الذكي
واجهة الصياغة الإدارية والفنية موجودة، لكنها غير مفعّلة بعد. يلزم ربط مزود ذكاء اصطناعي ونشر Edge Function آمنة مع تخزين مفتاح المزود كـ Secret على الخادم. لا تضع مفتاح API في الواجهة أو إعدادات المتصفح. لا يتم الادعاء بأن الصياغة الذكية تعمل قبل إعداد الخدمة واختبارها.

## البيانات والخصوصية
- السجلات تبقى محفوظة محلياً، وتتم مزامنتها إلى الحساب بعد تسجيل الدخول.
- تنزيل نسخة احتياطية دورياً إجراء احترازي جيد.
- راجع كل تقرير وصياغة قبل مشاركتها أو اعتمادها.
- التعرف الصوتي يعتمد على المتصفح وقد يخطئ في أسماء المعدات والأرقام؛ راجع النص قبل الحفظ.
- التطبيق لا يفترض سبب العطل أو نجاح الإصلاح من تلقاء نفسه.
