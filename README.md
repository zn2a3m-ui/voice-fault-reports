# مساعد مشرف الصيانة

تطبيق ويب عربي (PWA) لإدارة أعمال الصيانة ومتابعة الأعطال في بيئة مسالخ وتجهيز الدواجن. النسخة الحالية هي نقطة الانطلاق، والخطة المستقبلية موثقة في [تصور المنتج الجديد](docs/PRODUCT_BLUEPRINT_AR.md).

## الوظائف الموجودة حالياً

- **الأعطال والملاحظات الفنية:** إدخال نصي أو صوتي، تصنيف حسب التخصص والحالة، حفظ الوصف الأصلي، وصياغة تقرير إداري وفني.
- **التحليل الفني الأولي:** فصل المعلومات المؤكدة عن الاحتمالات والفحوصات المقترحة، مع التنبيه إلى حدود المراجع العامة والسلامة.
- **تقارير الإنتاج:** وصف الحالة بالصوت أو النص ثم إعداد تقرير مهني.
- **تقارير الشفت والتسليم والاستلام:** توثيق الأعمال المنجزة والمتبقية والملاحظات المفتوحة.
- **قطع الغيار:** تسجيل الطلبات والكميات والأولوية وسبب الطلب.
- **السجلات والنسخ الاحتياطي:** عرض السجلات ونسخها ومشاركتها وتصديرها، مع تنزيل نسخة JSON واستيرادها.
- **المزامنة:** حفظ محلي ومزامنة سحابية عبر Supabase مع تفعيل RLS على جداول البيانات.

## الصوت والذكاء الاصطناعي

- التسجيل يتم عبر `MediaRecorder` بعد موافقة المستخدم على الميكروفون.
- عند إيقاف التسجيل، يُرسل ملف الصوت إلى Supabase Edge Function، ثم إلى Groq Whisper (`whisper-large-v3`) لتحويله إلى نص عربي.
- يُضاف النص المتعرف عليه إلى حقل الوصف؛ ولا تُشغّل صياغة التقرير تلقائياً. تبقى الصياغة خطوة منفصلة يطلبها المستخدم.
- تعليمات التفريغ تستهدف اللهجة الأردنية/الفلسطينية ومصطلحات مسالخ الدواجن، لكن دقة أسماء المعدات والأرقام واللهجة يجب التحقق منها على تسجيلات حقيقية من أجهزة Android.
- الصياغة والتحليل الفني يمران عبر Edge Function. مفتاح Groq محفوظ في أسرار الخادم ولا يوضع في ملفات الواجهة.
- حدود الاستخدام والتوفر المجاني تخضع لسياسة Groq الحالية؛ لا يضمن التطبيق معالجة غير محدودة أو توافراً دائماً.
- لا يجوز للمساعد اختراع سبب العطل أو الإجراء المنفذ أو نجاح الإصلاح أو أرقام الإنتاج. يجب أن يميز بين الوقائع والاحتمالات والتوصيات.

## الأمان والبيانات

- جداول البيانات الحالية مفعّل عليها RLS، والسياسات الحالية مبنية على ملكية المستخدم.
- يستخدم التطبيق Publishable key في المتصفح، ولا يضع مفاتيح الخدمة السرية في الواجهة.
- خدمة الذكاء الاصطناعي تتحقق من جلسة المستخدم وهوية الحساب المصرح له قبل المعالجة.
- تبقى البيانات المحلية على الجهاز عند تسجيل الخروج. يجب الاحتفاظ بنسخة احتياطية قبل أي ترحيل أو تغيير في بنية البيانات.
- لا تحذف بيانات المتصفح أو التطبيق قبل التأكد من وجود نسخة احتياطية سليمة.

## النشر والتحديث

يتم النشر عبر GitHub Actions عند تحديث الفرع `main`. التطبيق الحالي PWA قابل للتثبيت من Chrome على Android. تثبيته لا يعني أنه منشور على Google Play.
